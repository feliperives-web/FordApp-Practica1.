- Descripción del Proyecto

Este repositorio contiene el prototipo de una aplicación de escritorio desarrollada con Microsoft Blend (tecnología WPF).

Nota sobre los requisitos: Aunque el enunciado original del caso práctico plantea el desarrollo para la marca Polestar, este proyecto se ha desarrollado en torno a la marca Ford, contando con la autorización explícita del equipo docente para realizar esta adaptación.

El objetivo principal de este prototipo es aplicar conceptos fundamentales de diseño de interfaces, guías de estilo, estándares de usabilidad e interacción humano-ordenador (HCI), asegurando una experiencia de usuario (UX) funcional, accesible y agradable.

- Estructura de la Aplicación

La aplicación se compone de tres secciones principales y elementos transversales:

Pantalla de Inicio: Destaca los vehículos de Ford más novedosos, mejores precios y campañas actuales.

Galería de Productos: Un catálogo visual completo para explorar los modelos disponibles.

Pantalla de Login: Área de identificación de clientes que incluye ocultación de contraseña y gestión visual de errores (feedback claro en caso de credenciales incorrectas).

Elementos Comunes: Todas las pantallas incluyen, de forma consistente, el logotipo de Ford y un menú de navegación principal.

Interacción: Se han implementado animaciones sutiles (transiciones, hover en botones) en su justa medida para guiar al usuario sin sobrecargar la interfaz.

- Tecnologías y Herramientas Utilizadas

Entorno de desarrollo: Microsoft Blend for Visual Studio

Tecnología: WPF (Windows Presentation Foundation)

Lenguajes: XAML (Diseño UI) y C# (Lógica base)
